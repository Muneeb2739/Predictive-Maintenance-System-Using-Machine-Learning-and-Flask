# Predictive-Maintenance-System-Using-Machine-Learning-and-Flask

## About the Project

This project predicts whether a machine is likely to fail based on its sensor data. I built this project using Python, Machine Learning, and Flask.

The goal is to help identify possible machine failures early and support better maintenance decisions.

## Features

- Predict machine failure using sensor readings.
- Upload a CSV file to predict failures for multiple machines.
- View predictions and failure probabilities.
- Explore model performance through a dashboard.
- Download batch prediction results.

## Technologies Used

- Python
- Flask
- Pandas and NumPy
- Scikit-learn
- HTML and CSS
- Matplotlib and Seaborn

## How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/Muneeb2739/Predictive-Maintenance-System-Using-Machine-Learning-and-Flask.git
   ```

2. Open the project folder:

   ```bash
   cd Predictive-Maintenance-System-Using-Machine-Learning-and-Flask
   ```

3. Install the required libraries:

   ```bash
   pip install -r requirements.txt
   ```

4. Start the application:

   ```bash
   python app.py
   ```

5. Open `http://127.0.0.1:5000` in your browser.
